## 🚀 Bachelor's thesis

**Quantitative Modeling of Energy Consumption and Carbon Impact of AI Inference Workloads**

My thesis focused on modeling GPU-cluster energy consumption for AI inference workloads using Python-based simulation. The project combines workload modeling, queueing-inspired utilization analysis, GPU power states, provisioning strategies, and energy-versus-service-quality trade-offs.

Main topics:

* AI inference workload modeling
* GPU cluster utilization
* Energy consumption estimation
* Python simulation and data analysis
* Queueing-inspired capacity modeling
* Autoscaling and provisioning strategies
* SLA-risk analysis
